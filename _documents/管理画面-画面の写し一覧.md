# 管理画面の画面の写し一覧

管理画面（Svelte。`src/VehicleVision.PleasanterTools.CalendarFeed.Frontend`）の画面の写し。**手で撮らず、スクリプトで撮り直せる**
（[`tools/screenshots/`](../tools/screenshots/README.md)）。実際の初回の流れ（最初の管理者 → 設定 → フィード → 招待 → 2 要素）を辿って撮っており、
Pleasanter は偽物（予定 3 件を返す小さな HTTP サーバ）に向けている。画面が変わったら撮り直す。

- 画面の文言は 7 言語（日本語・英語・中国語・ドイツ語・韓国語・スペイン語・ベトナム語）。言語は「保存した選択 → ログイン中の利用者の言語 → ブラウザの言語設定 → 日本語」の順で決める。
- 画面の出し分けは**役割ではなく権限**で行う（`GET /admin/api/me/` の `permissions`）。
- 画面から編集できる設定は DB へ保管される（[`導入-更新運用手順書.md`](導入-更新運用手順書.md) の「アプリケーション設定」）。
